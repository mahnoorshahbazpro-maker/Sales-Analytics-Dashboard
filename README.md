# 📊 Sales Analytics Dashboard

An interactive sales analytics dashboard built using Python, Pandas, Streamlit, and Plotly.

## 🚀 Live Demo
https://sales-analytics-dashboard-styj7cbgaktesh97ft7ze9.streamlit.app/

## ✨ Features
- Total Revenue, Orders, Units Sold, and Average Sale KPIs
- Monthly Revenue Trend Analysis
- Product Performance Analysis
- City-wise Sales Analysis
- Category-wise Revenue Analysis
- Interactive filters for cities and categories
- CSV file upload

## 🛠️ Technologies Used
- Python
- Pandas
- Streamlit
- Plotly

## 🎯 Project Objective
To analyze sales data and present useful business insights through interactive visualizations.
